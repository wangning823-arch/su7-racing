# AI赛道测试计划

## 一、测试目标
验证AI在所有赛道上的表现，检测以下问题：
1. AI无法启动或长时间不动
2. AI在弯道撞墙卡住
3. AI掉出赛道
4. AI无法完成比赛

## 二、测试流程

### 单赛道测试流程
1. **加载游戏** (约30秒)
   - 启动headless浏览器
   - 劫持requestAnimationFrame
   - 加载游戏页面

2. **开始比赛** (约40秒)
   - 选择指定赛道
   - 等待倒计时结束
   - 确认比赛状态为RACING

3. **监控AI** (最长10分钟)
   - 每秒采集AI状态（位置、速度、splineT、检查点）
   - 检测卡住（splineT不变 + 速度<2 持续30秒）
   - 检测掉出赛道（y < -10）
   - 定期截图记录运行过程

4. **输出报告**
   - JSON格式结果
   - 包含：是否通过、原因、AI历史数据、截图路径

### 全赛道批量测试
- 串行测试所有30个赛道
- 每个赛道最长10分钟
- 总时长约5小时

## 三、问题诊断

### 截图分析
- 在卡住时自动截图
- 人工分析截图判断卡住原因：
  - 撞墙：AI贴近护栏
  - 掉落：AI在赛道外
  - 起点不动：游戏未正常启动

### 数据分析
- splineT变化：判断AI是否在前进
- 速度变化：判断AI是否被卡住
- 检查点通过：判断AI是否在正确路径上

## 四、已知问题
- headless模式帧率很低（~3fps）
- 需要等待40秒让倒计时结束
- 每个赛道测试需要5-10分钟
